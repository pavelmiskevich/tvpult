# tvpult

**Пульт для телевизоров Samsung в домашней сети.** Сам находит телевизоры и управляет ими из окна браузера —
без облака, аккаунтов и магазинов приложений. Двойной щелчок по ярлыку на рабочем столе — открывается пульт;
закрыл окно — всё остановилось.

[English version](README.md)

> **Статус: ранняя версия.** Каждый день работает с двумя Samsung (2017, Tizen 3.0 и 2022, Tizen 6.5).
> Мастер настройки, пакет PyPI и установщик для Windows — в планах.

## Что умеет

- Кнопки пульта без задержки (~10 мс), быстрый запуск приложений (YouTube, Кинопоиск, Okko, PREMIER, браузер…).
- Видно, что на экране и к какой точке Wi-Fi подключён ТВ.
- Ввод текста на ТВ с телефона или ноутбука (поиск, пароли).
- Включение по сети (где ТВ поддерживает) и выключение; громкость саундбаров и колонок Google Cast.
- Сам находит устройства, если сменились адреса или сеть, — по MAC/UUID с проверкой по ARP-таблице,
  чтобы другое устройство в сети не могло выдать себя за ваш ТВ.
- Ярлык на рабочем столе: без окна консоли, пульт отдельным окном, закрыл — через ~10 с остановился.

## Быстрый старт

Нужен [uv](https://docs.astral.sh/uv/) — он сам поставит Python 3.12 и библиотеки.

```powershell
git clone https://github.com/pavelmiskevich/tvpult
cd tvpult
uv run tvpult shortcut                   # ярлык «Пульт ТВ» на рабочем столе
```

Включите телевизоры и дважды щёлкните по ярлыку. В первый раз откроется **мастер настройки**: он найдёт
все Samsung в сети — дайте каждому имя, нажмите **«Подключить»** и **«Разрешить»** на экране ТВ. Ещё
телевизор позже — вкладка **«+ ТВ»**. Файлы править не нужно. (Из командной строки: `tvpult find --all` —
все ТВ в сети, `tvpult init` — начать конфиг вручную.)

Настройки и данные лежат в папке пользователя, а не рядом с кодом: `tvpult paths` покажет где
(Windows: `%LOCALAPPDATA%\tvpult`).

## Безопасность

Только локальная сеть; страничка слушает `127.0.0.1`; сервисные кнопки запрещены; личность устройства
проверяется перед каждой командой; запросы с чужих сайтов отклоняются. **Не пробрасывайте порт пульта в роутере.**
Откат: удалить `tvpult` из списка подключённых устройств на ТВ и удалить папку.
